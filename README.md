# Сервис управления личными заметками (REST API)

Проект выполнен в рамках учебной технологической практики (2026 г.) на направлении 01.03.02 "Прикладная математика и информатика". 
Основная база проекта подготовлена в ходе изучения 36-часового специализированного курса backend-разработки на платформе Stepik.

## Структура репозитория
* `app/` — исходный код серверного ПО (Flask, SQLAlchemy)
* `tests/` — автоматические модульные тесты (pytest)
* `log_analyzer.py` — оптимизированный скрипт аналитики логов со сложностью O(N)
* `Dockerfile` — конфигурация автоматического развертывания среды

## Инструкция по локальному запуску (Автоматизация сред)
Для изоляции приложения и зависимостей используется технология контейнеризации Docker.

1. Сборка Docker-образа системы:
```bash
docker build -t notes-api-service .
```
2. Запуск изолированного контейнера:
```bash
docker run -d -p 5000:5000 --name notes-app notes-api-service
```
Приложение станет доступно по адресу: `http://127.0.0.1:5000`

## Автоматическое тестирование
Запуск модульных тестов в изолированной базе данных прямо из корня проекта:
```bash
python -m pytest
```

## Примеры API-запросов (curl / Postman)

1. Добавление новой заметки (Метод: POST)
* Запрос:
```bash
curl -X POST http://127.0.0 \
-H "Content-Type: application/json" \
-d "{\"title\": \"Задание СВФУ\", \"content\": \"Защитить отчет у Акимова М.П.\"}"
```
* Ответ сервера (`201 CREATED`):
```json
{"id": 1, "message": "Note created successfully"}
```

2. Получение списка заметок с пагинацией (Метод: GET)
* Запрос:
```bash
curl -X GET "http://127.0.0?page=1&per_page=5"
```

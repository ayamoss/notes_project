# Сервис управления личными заметками (REST API)

Проект разработан в рамках учебной технологической практики (2026 г.) студентом группы ПМИ-24 направления **01.03.02 «Прикладная математика и информатика»** СВФУ. 

Основная база проекта, архитектурные концепции и навыки работы со стеком технологий сформированы в ходе прохождения специализированного **36-часового практического онлайн-курса на платформе Stepik**.

---

## 🛠 Технологический стек проекта
* **Язык программирования:** Python 3.12
* **Серверный веб-фреймворк:** Flask
* **Инструментарий работы с БД:** SQLAlchemy ORM (СУБД PostgreSQL в production, SQLite для локального тестирования)
* **Автоматическое тестирование:** pytest
* **Контейнеризация и DevOps:** Docker, Gunicorn, Nginx
* **Облачный продакшен-хостинг:** Render

## 🚀 Инструкция по локальному запуску и автоматизации сред

Для обеспечения независимости работы ИТ-системы от операционной системы хоста и автоматизации развертывания используется контейнеризация **Docker**.

### Вариант 1. Запуск в изолированном Docker-контейнере (Рекомендуемый)
1. Убедитесь, что у вас запущен Docker Desktop.
2. Соберите Docker-образ приложения из корневой директории:
   ```bash
   docker build -t notes-api-service .
   ```
3. Запустите контейнер в фоновом режиме с пробросом портов:
   ```bash
   docker run -d -p 5000:5000 --name notes-app notes-api-service
   ```
4. Сервис станет доступен по адресу: `http://127.0.0.1:5000`

### Вариант 2. Классический запуск в виртуальном окружении Python
1. Создайте и активируйте окружение `venv`:
   ```bash
   python -m venv .venv
   # Для Windows (Git Bash / PowerShell):
   source .venv/Scripts/activate
   ```
2. Установите зафиксированные зависимости проекта:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите сервер разработки:
   ```bash
   python -m app.routes
   ```

## 📈 Примеры API-запросов (Инструкция по проверке CRUD через curl / Postman)

Поскольку программный комплекс является Backend-приложением и не имеет графического интерфейса, для ручной отладки использовались утилиты **Postman** и консольный клиент **curl**.

### 1. Добавление новой заметки в базу данных (Операция Create — метод POST)
* **HTTP URL:** `http://127.0.0`
* **Запрос (curl):**
```bash
curl -X POST http://127.0.0 \
-H "Content-Type: application/json" \
-d "{\"title\": \"Учеба СВФУ\", \"content\": \"Защитить отчет по учебной практике у Акимова М.П.\"}"
```
* **Ожидаемый ответ сервера (`HTTP/1.1 201 Created`):**
```json
{
  "id": 1,
  "message": "Note created successfully"
}
```

### 2. Чтение списка заметок с пагинацией и фильтрацией (Операция Read — метод GET)
* **HTTP URL:** `http://127.0.0?page=1&per_page=5`
* **Запрос (curl):**
```bash
curl -X GET "http://127.0.0?page=1&per_page=5"
```
* **Ожидаемый ответ сервера (`HTTP/1.1 200 OK`):**
```json
{
  "current_page": 1,
  "notes": [
    {
      "id": 1,
      "title": "Учеба СВФУ",
      "content": "Защитить отчет по учебной практике у Акимова М.П."
    }
  ],
  "total_pages": 1
}
```

### 3. Пример обработки ошибок валидации данных сервером
* **Запрос (Передано пустое поле контента):**
```bash
curl -X POST http://127.0.0 \
-H "Content-Type: application/json" \
-d "{\"title\": \"Пустая заметка\"}"
```
* **Ожидаемый ответ сервера (`HTTP/1.1 400 Bad Request`):**
```json
{
  "error": "Bad Request. Missing fields"
}
```
